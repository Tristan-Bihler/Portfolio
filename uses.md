The tools I actually use — on the workbench, on the trail, and on this machine.

## Workbench

- **Soldering station** — temperature-controlled, the single most-used tool on the bench
- **Digital multimeter** — the first thing I reach for when something doesn't work
- **Oscilloscope** — for everything the multimeter can't see
- **Lab power supply** — adjustable voltage & current limiting, saves components daily
- A well-sorted assortment of resistors, capacitors and jumper wires that
  somehow still never has the one value I need

## Software

- **VS Code** — main editor for everything from Python to SCSS
- **Python** with OpenCV, NumPy and PyQt5 — the stack behind my AOI machine
- **Git & GitHub** — version control for code and for this site
- **Jekyll** — static site generator powering exactly what you're reading
- **Claude Code** — AI pair programmer for building and debugging

## Photography & Outdoors

- **Canon DSLR** — the `_MG_` filenames all over my travel posts give it away
- **Google Pixel** — the camera that's always in my pocket
- Solid hiking boots, a rain jacket that has seen things, and a tent that has
  survived Norwegian weather
